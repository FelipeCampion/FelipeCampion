## 🚀 Projeto em destaque

### 🧪 Atlan LIMS: gestão laboratorial e ERP para a indústria

**Primeiro grande projeto da Atlan.** Sistema web completo que reúne **qualidade, logística, estoque e financeiro** em um só lugar, desenvolvido para a rotina de uma indústria.

| Módulo | O que entrega |
|---|---|
| 📈 **Qualidade por lote** | Histórico de resultados por lote, teste, cliente e período, com comparativo de variância em gráfico |
| 🎯 **Controle Estatístico de Processo** | Variação entre amostras, pontos fora de especificação em destaque e **selo de estabilidade de pH** (amplitude de até 1,0 por no mínimo 3 dias contínuos) |
| 🗄️ **Contraprovas** | Arquivo físico de amostras retidas, com localização, status e baixa |
| 📄 **Laudos em PDF** | Certificados oficiais gerados a partir do histórico analítico |
| 🚚 **Logística** | Cargas e descargas integradas, com status da operação, NFs, lotes e relatório oficial filtrável |
| 📦 **Estoque** | Controle de itens e EPIs, com alerta de reposição e ficha por funcionário |
| 💰 **Financeiro e clientes** | Fluxo de caixa, projeção mensal e carteira de clientes |

**Stack:** HTML5 · JavaScript (vanilla) · Tailwind CSS · Firebase Firestore · Chart.js · html2pdf.js

## 🛠️ O que eu desenvolvo

- **Arquitetura & segurança de dados:** modelagem relacional (DER/MER) com foco em integridade, escalabilidade e proteção de dados críticos no nível do motor (RDBMS).
- **Aplicações full-stack:** interfaces web em JavaScript e Tailwind integradas a Firebase e Node.js, com gráficos, relatórios em PDF e regras de negócio reais.
- **Backend & APIs:** servidores em **Node.js** conectados a bancos de dados, de infraestruturas robustas a arquiteturas locais eficientes e com custo zero de hospedagem.
- **Sistemas distribuídos:** integração de múltiplos bancos via **Synonyms**, com segregação de domínios e interoperabilidade.
- **Automação & lógica no servidor:** Triggers, Stored Procedures e Views para garantir consistência dos dados e automatizar processos.
